# 2Dサッカー (ymt-game01)

ブラウザで遊べる 2D サッカーゲームです。ウイニングイレブンのように、
ボールに関わる 1 人をユーザーが操作し、残りの選手は AI が自動で動きます。

- 9 人制 (GK + フィールド 8 人)、3-3-2 フォーメーション
- ピッチは 116m x 76m (9人制に合わせて標準より少し広め)
- 味方チーム **BLUES (青)** vs 敵チーム **REDS (赤)**
- 前半 5 分 + 後半 5 分 (タイトル画面の設定で 1〜10 分に変更可能)。
  それぞれの終わりに**アディショナルタイム**がランダムで加算されます
- **スプリント** (Shift / スティック外周) でスタミナを消費して加速。
  走らせ続けた守備は息切れするので、体力の削り合いが駆け引きになります
- **スルーパス** (Z 長押し) でラインの裏へ走らせる攻撃ができ、
  パスが行く味方には常にマーカーが出ます
- 好プレーで **モメンタム (ノリ) ゲージ** が溜まり、満タンで 15 秒間の
  **ゾーン** (加速・スタミナ無消費・シュート精度上昇) に突入します
- DF を振り切って GK と **1 対 1** になると読み合いのミニゲームに突入します
- 後半終了時に同点なら **PK 戦** (3人 + 決着つかなければサドンデス) で
  必ず決着をつけます
- カメラはボールを追従してスクロール。右下 (タッチ操作端末では右上) のミニ
  マップで全体の陣形を確認できます
- **PWA 対応**: スマホ (Android/iOS) では仮想スティック+ボタンのタッチ操作
  で遊べ、ホーム画面に追加すればアプリのようにオフラインでも起動できます
- 通算成績 (勝敗・連勝記録・トーナメント優勝回数) を端末に保存し、
  タイトル画面に表示します
- **モード選択**: タイトル画面で「単発試合」と「トーナメント (ベスト16)」を
  選べます (下記「トーナメントモード」参照)

## 起動方法

`index.html` をブラウザで開くだけで動きます (ビルド・外部ライブラリ不要)。

ローカルサーバーを使う場合:

```bash
python3 -m http.server 8000
# → http://localhost:8000 を開く
```

**注意:** PWA 機能 (Service Worker・ホーム画面への追加) は `file://` で直接
開いた場合は動作しません。`http://` または `https://` 経由で配信したときだけ
有効になります (下記「スマホにインストールする」参照)。

## 操作方法

| キー | 攻撃時 (ボール保持) | 守備時 |
|---|---|---|
| 矢印キー | ドリブル | 移動 |
| Shift | スプリント (スタミナを消費して加速) | 同左 |
| Z | パス (入力方向の味方へ)。**長押しでスルーパス**、相手ゴールライン際のサイドでは長押しでクロス | スライディング |
| X | シュート (長押しで強く、上下入力でコース調整) | スライディング |
| Space | - | 操作選手の手動切替 |
| Esc | ポーズ | ポーズ |
| Enter | タイトル: 試合開始 / ハーフタイム: 後半開始 | 同左 |

選手の移動速度は通常は全員同じ (基準速度の 1.0 倍) です。「その日の調子」
として、各チームからランダムに最大 3 人が絶好調 (基準速度の 1.1 倍) になり、
髪が青色になって見分けられます。

### スプリント

**Shift を押している間だけ 1.18 倍に加速**します。スタミナを一気に消費する
ため、満タンからでも約 14 秒しか続きません (緩めれば回復)。スタミナが
尽きるとスプリントできなくなり、通常の速度も最大 18% 落ちます。

守備 AI のチェイサー (ボールを追う担当) も同じ仕組みで加速するため、
**走らされ続けた守備は終盤に息切れして振り切られる**という駆け引きが
生まれます。逆に、こちらが無駄にスプリントを続けるとカウンターで
戻れなくなります。

### パス相手のマーカーとスルーパス

ボールを保持している間、**いま Z を押したらパスが行く味方に印が表示**
されます。スティック/矢印キーで方向を変えると印も移動するので、狙いを
定めてから出せます。

Z を長押しすると印が紫に変わり、**その味方の前のスペースへ転がす
スルーパス**になります (受け手が走り込む形になり、操作も自動で受け手へ
移ります)。オフサイドはパスを出した瞬間の位置で判定されるため、
「ラインの裏を取る」駆け引きになります。相手ゴールライン際のサイドに
いる場合は、長押しは従来どおりクロスになります。

### タッチ操作 (スマホ・タブレット)

指で操作できる端末 (`pointer: coarse`) では、キーボードの代わりに以下の
タッチ UI が自動的に表示されます (プレー中のみ。タイトル/ポーズ/ハーフ
タイム/リザルト画面では下のメニューが隠れないよう非表示になります)。

| タッチ操作 | 表示ラベル | 対応するキー |
|---|---|---|
| 左側の仮想スティック | - | 矢印キー (ドリブル/移動) |
| 右側ボタン (長押し可) | パス/スラ (味方 GK 保持中は ショート) | Z |
| 右側ボタン (大) | シュート/スラ (味方 GK 保持中は ロング) | X |
| 右側ボタン (小) | 切替 | Space (手動切替) |
| 右上ボタン | ⏸ | Esc (ポーズ) |
| 左上ボタン | ⛶ (全画面切替) | - |

Z/X ボタンは「攻撃時 / 守備時」の機能名を併記しており、キー名ではなく
操作の意味がひと目でわかるようにしています。味方 GK がボールを保持した
瞬間だけ、表示が「ショート / ロング」キックに切り替わります。
キーボードとタッチは同じ入力として扱われるため (`js/input.js`)、両方を
同時に使うこともできます。仮想スティックは倒した方向へ常にフル速度の
入力になります (押している間だけ有効な矢印キーと同じ挙動)。中心付近
(見た目の点線の輪、スティック直径の 18%) はニュートラル扱いになる
「ドーナツ」型で、指が中心から少しズレただけで意図しない方向に入って
しまうのを防いでいます (`js/touch.js` の `DEADZONE_RATIO`)。

**スプリントはボタンを増やさず、スティックを外周 (半径の 85% 以上) まで
倒し込むことで発動します。** スプリント中はノブが黄色く光るので、
今加速しているかが指を離さずに分かります (`SPRINT_CONF.STICK_RATIO`)。

**横向き画面ではピッチの左右に専用の余白 (ガター) を確保し、そこに
ジョイスティック・ボタン類を配置します** (`#touch-controls` を `position:
fixed` にして画面全体を基準に配置し、その分だけピッチ (`#stage`) を
狭めることで実現)。ボタンがピッチの描画に重ならないため、プレー画面を
指で隠さずに操作できます。

タッチ操作端末では、試合開始・後半開始・ポーズ再開時に全画面表示 (Fullscreen
API) を試みます。あわせて左上に全画面切替ボタン (⛶) を常時表示している
ので、自動での全画面化が効かない場合や、後から全画面/通常表示を切り替え
たい場合はこのボタンで手動トグルできます (非対応のブラウザでは何も起きず
通常表示のまま遊べます)。

### 攻守フェーズについて

守備アクション (スライディング) は「守備状態」のときだけ発動します。
守備状態になるのは、相手がボールを保持しているか、相手が最後に触った
ルーズボールのときだけです。味方が保持してから相手が触るまで
(味方同士のパスの飛行中を含む) は攻撃状態のままなので、パス直後に
受け手が誤ってスライディングすることはありません。

### 操作キャラの切替について

- 味方がボールを持つと、自動で保持者に操作が移ります (パス時は受け手へ)
- 守備時は「ボールと自ゴールを結んだ直線」の近くに居てボールに近い味方へ
  自動で切替わります。ピッチの前後方向でボールより敵陣側 (前) に出ている
  選手は、その距離に比例したペナルティを科して選ばれにくくしています。
  横 (左右) にどれだけずれていても、ボールより前にいる選手は守備に
  間に合わないため確実に除外されます (`js/match.js` の `defensiveScore`)
- 頻繁に切替わりすぎないよう、以下のヒステリシスを入れています
  (`js/config.js` の `SWITCH_CONF`)
  - 切替後 0.9 秒間は自動切替をロック
  - 候補の優先度が「現在の操作キャラ × 0.68」より良い、または差が一定以上
    開いたときだけ切替
  - **矢印キーやアクションキー (Z/X) を何か操作している間は自動切替
    が起きません**。キーを離して無入力の状態が 8 フレーム続いたときだけ
    切替の判定が働きます。操作中のキャラが急に切り替わって横取りされる
    ことを防ぐためです
  - ただし、**現在の操作キャラがボールから離れすぎている場合は、入力中でも
    無入力を待たず即座に切替わります** (`SWITCH_CONF.FAR_OVERRIDE_GAP`)。
    見当違いの選手を操作し続けてしまうのを防ぎます
- Space キーで手動切替: 守備優先度の高い順に巡回します (押すたびに次の候補へ)。
  無入力判定に関係なく即座に効き、手動切替後は 1.5 秒間、自動切替をロック
  してユーザーの選択を優先します

## ルール (簡略化)

- タッチラインを割ると相手ボールのキックイン
- ゴールラインを割るとゴールキック / コーナーキック
- キックイン・コーナーキックは**必ずパスから再開**します
  (出し手はその場から動けず、矢印キーで向きを変えて Z でパス)
- 選手の移動速度は通常は全員同じ (基準速度の 1.0 倍) です。「その日の
  調子」として各チーム最大 3 人だけが絶好調 (1.1 倍、髪が青色で表示)
  になります。ただしボール保持中のドリブル速度は、絶好調の上限をかけても
  フリーで走る DF の基準速度よりわずかに遅くなるよう調整してあり、
  さらに守備側のチェイサーは追走時に加速するため、ドリブルだけで
  独走突破はできません
- **スタミナ (疲労)**: スプリント (Shift) で大きく消費し、動きを緩めれば
  回復します。尽きると速度が最大 18% 低下し、スプリント自体もできなく
  なります。ハーフタイムでも少しだけ回復しますが、完全回復はしません。
  操作中の選手の足元にスタミナゲージが表示されます
  (緑→オレンジ→赤の順で減少。スプリント中は枠が黄色く光ります)
- **ファウル (軽量版)**: スライディングタックルが相手に接触すると、
  相手の背後から追い越しざまに刈った場合は高確率、それ以外は低確率で
  ファウルを取られます。ファウルを取られた地点から相手ボールのフリー
  キックで再開します。同じ選手が2回目以降のファウルを犯すと「警告」
  として表示されますが、退場にはなりません (人数が変わる大掛かりな
  変更を避けるため)
- **オフサイド**: パスを出した瞬間、受け手が相手陣内かつ相手の最終ライン
  (GK を除く一番後ろの選手) より前に出ていて、かつパスの出し手より前
  にいるとオフサイドになり、相手ボールの間接フリーキックで再開します。
  キックイン・コーナーキック・ゴールキックなどのリスタートは対象外です
  (実際のルール通り)。クロスやロングキックなど、パス以外での配球は
  判定の対象外です (軽量版としての割り切り)。サイドバックは自陣センター
  バックより一定距離前を維持するよう動くため、最終ラインがゴール前まで
  下がりきってオフサイドが発生しにくくなる、という状況を防いでいます
- ファウル・オフサイドなどでリスタートになると、その瞬間の全選手の
  スライディング・転倒などのアクション状態は解除され、一旦仕切り直して
  からフリーキック/間接フリーキックとして再開します
- リスタートの出し手がボールを離す (パスを出す) までは、敵味方問わず
  出し手に対してスライディング・タックルを仕掛けられず、さらに相手
  チームの選手は一定距離 (8m) より出し手に近づけません
  (蹴り出す前にボールを奪われたり、囲まれてしまうことを防止)
- GK はペナルティエリア内でシュートをキャッチします。味方 GK が保持した瞬間、
  操作キャラが GK に切り替わり、ユーザーが Z / X でキックを選べます
  (下記「GK のキック」参照)。相手チームは GK 保持中プレスに来ません (奪えません)
- 前後半それぞれの終わりに、**アディショナルタイム (ロスタイム)** が
  30 秒〜2 分 30 秒の範囲でランダムに加算されます。突入時にバナーで告知し、
  以降はスコアボードの時計に「+1:23」のように別建てで表示されます
- 後半終了時に同点なら **PK 戦**に突入し、必ず勝敗を決めます (下記参照)

## モメンタム (ノリ) とゾーン

画面左上に両チームの**モメンタムゲージ**があります。良いプレーをするほど
溜まり、**満タンになるとそのチームが 15 秒間「ゾーン」に突入**します。

溜まる / 減る条件:

| イベント | 増減 |
|---|---|
| パス成功 | +4 |
| タックル・スライディングでボール奪取 | +8 |
| ワンタッチパス (ワンツー) | +9 |
| スルーパス成功 / クロスが通る | +10 |
| 枠内シュート | +13 |
| ゴール | +33 |
| 相手にボールを奪われる | -4 |
| 失点 | -25 |
| ボールを保持していない間 | 毎秒 -0.5 |

自然減少は**ボールを保持していない間だけ**効くため、繋いで攻め続けている
限りゲージは減りません。

**ゾーン中の効果** (チーム全員に適用):

- 移動速度が 1.12 倍
- スプリントしてもスタミナが減らない (息切れしていても走れる)
- シュートの誤差が約半分になり、狙ったコースへ飛びやすい
- ゲージが残り時間バーに変わり、画面の縁がチームカラーで脈打ちます

CPU 側も同じ条件でゾーンに入るので、**相手がゾーンに入ったら耐えしのぐ**
という展開も生まれます。10 分の試合でだいたい 1〜3 回発動する程度の
ペースになるよう調整してあります (`MOMENTUM_CONF`)。

## 1 対 1 (ブレイクアウェイ)

DF を完全に振り切って GK と 1 対 1 になると、**PK と同じコース読み合いの
ミニゲームに突入**します。

- **発動条件**: 相手ゴールから 26m 以内でボールを保持し、相手フィールド
  プレーヤーが全員 7m 以上離れていること。一度発動すると 25 秒は再発動
  しません (`BREAKAWAY_CONF`)
- 制限時間は PK より短い 2.2 秒。コースを選んで **X で決定**します
- 自分が抜け出した場合は**キッカー視点**、相手が抜け出した場合は
  **キーパー視点**(自分が飛ぶ方向を選ぶ) になります
- 結果は 3 通り:
  - **読み勝ち** → ゴール
  - **読み負け** (コース一致) → GK セーブ。GK が保持して再開
  - **ポスト直撃** (読み勝ち時に 15%) → ゴール前にこぼれ球。詰めればチャンス
- PK と違い**試合は止まりません**。決着後はそのまま通常プレーに戻ります

## 演出

- **カメラズーム**: ボールがどちらかのゴールに近づくほど自動的に寄ります
  (中盤で 12px/m → ゴール前で 15.5px/m)
- **画面シェイク**: ゴール、ポスト直撃、ゾーン発動時
- **ヒットストップ**: ゴールの瞬間に約 0.12 秒だけ画面が止まり、
  インパクトを強調します
- **終盤スローモー**: 後半の残り 30 秒以内 (ロスタイム込み) に枠内シュートが
  飛ぶと、約 0.9 秒だけ時間が 0.35 倍になります
- **スプリントの砂煙**: スプリント中の選手の足元にエフェクトが出るため、
  誰が加速しているか一目で分かります

演出タイマーはすべて実時間で進むため、ヒットストップやスローモー自体が
遅延して伸びることはありません (`FX_CONF`)。

### PK 戦

後半終了時点で同点の場合、その場で PK 戦が始まります。自分のチームが
蹴る番か・守る番かによって、1人称視点が自動で切り替わります。

- 3 人ずつ交互に蹴り、それでも決着がつかなければ 1 本ずつのサドンデスに
  突入します (先攻/後攻はランダム)
- ゴールは**左/中央/右 × 上/下 の 6 ゾーン**に分かれています
  - 自分のチームが蹴る番: **キッカー視点** (ゴール正面) になり、相手 GK が
    ゴールの大きさに見合った等身でゴール中央に立って対峙します。矢印キーで
    コースを選び **X で決定**。結果発表時には相手 GK が選んだコースへ
    実際にダイブする様子が見えます (真ん中下段は飛ばずに止め、真ん中上段は
    その場で垂直にジャンプ、それ以外は手を伸ばして左右へダイブします)
  - 相手が蹴る番: **キーパー視点**になり、相手キッカーが正面に見えます。
    同じ 6 ゾーンから自分が飛ぶ方向を選び **X で決定**します。自分の GK も
    同じようにキャラクターとして表示され、選んだ方向へダイブします
  - どちらの役でも、制限時間内に選ばなければ今のカーソル位置でそのまま
    確定します
- キッカーとキーパーの選択はお互いに見えません。**コースが一致すればセーブ、
  外れればゴール**というシンプルな駆け引きです (何も読み合いをしない
  ランダム同士なら 1/6 の確率で一致する計算になります)
- CPU 側は完全ランダムにコース/飛ぶ方向を選びます
- 残り本数で逆転が不可能になった時点で、3 人消化前でも打ち切りになります
  (例: 2 本消化して 2 点差がついていれば 3 本目を待たずに決着)
- PK で決着した試合は、通算成績にもそのまま勝敗としてカウントされます

## トーナメントモード

タイトル画面の「モード」で **トーナメント (ベスト16)** を選ぶと、単発試合
とは別に、勝ち上がり式の4試合 (ベスト16 → 準々決勝 → 準決勝 → 決勝) に
挑戦できます。

- ラウンドごとに対戦相手 (チーム名・カラー) がランダムに変わります
  (15チームのプリセットから重複なく選出)
- ラウンドが進むごとに敵 AI が少しずつ強くなります (難易度セレクトを
  基準に、決勝では約 1.18 倍まで強化)
- 勝利すると「次のラウンドへ」ボタンで即座に次戦を開始できます
  (それ以外の試合の結果はシミュレートしません。自分が実際に戦う相手だけ
  が決まる、軽量な勝ち上がり方式です)
- 決勝に勝つと**優勝**となり、通算成績に優勝回数が記録されタイトル画面に
  表示されます。いずれかのラウンドで敗れる (またはタイトルへ戻る) と、
  その時点でトーナメントは終了します
- 各試合の勝敗は、トーナメントの勝ち上がりとは別に、通常の通算成績
  (勝敗・連勝記録) にもそのままカウントされます

## シュートと GK の駆け引き

X の長押しでシュートの強さが変わり、GK の対応も変わります:

- **弱いシュート** (溜めなし〜中程度): GK の正面ならキャッチされます
- **強いシュート** (しっかり溜める): GK はキャッチできず**弾く**だけになり、
  弾いた後しばらく倒れ込んで動けません → こぼれ球を押し込むチャンス
- **至近距離からの強いシュート**: ゴールに近いほど GK が反応しきれず、
  正面でも抜ける確率が上がります
- 近距離ほどシュートの精度も上がります (遠距離・強打はブレやすい)
- **強いシュートが直撃すると、GK に限らずフィールドプレーヤーも倒れます**
  (ブロックに入った選手が弾き返される演出。倒れている間は動けません)

### ダイレクトシュート (ワンタッチシュート)

相手ゴールに近い味方 (ゴールから 22m 以内) へパスを出すと、ボールが届く
**直前の 0.2 秒間だけ受け手が光ります**。その間に X を押すと、トラップせず
ダイレクトで強力なシュートを放ちます。

- 窓は 0.2 秒。人間の反射速度に対してシビアなので、パスを出した瞬間から
  タイミングを予測して押す必要があります
- 光る前に X を押してしまうと、そのパスではダイレクトシュートできません
  (連打では成功しない仕様)
- 調整は `js/config.js` の `VOLLEY_CONF` (窓の長さ・対象ゾーン・威力)

### ワンタッチパス (ワンツー)

ダイレクトシュートと同じ「光る窓」の仕組みを使い、パスが届く直前の 0.2 秒間に
**Z** を押すと、トラップせずその場で別の味方へワンタッチで繋ぎます。
矢印キーでパスした相手へそのまま返せば**ワンツー (壁パス)**、別方向に倒せば
**ダイレクトで展開する 3 人目へのパス**になります。

- ダイレクトシュート (X) とワンタッチパス (Z) は独立して判定されるので、
  ゴール前では両方の窓が同時に開くこともあります
- ワンタッチパスはピッチのどこでも成立します (シュートのようなゾーン制限なし)
- 早すぎる Z 押しは、ダイレクトシュートと同様にそのパスでの権利を失います
  (連打では成功しない仕様)

### GK のキック

味方 GK がボールを保持すると操作キャラが GK に切り替わり、専用のキーになります:

- **Z: 近くの味方へショートパス** — 距離の近さを最優先で相手を選びます
- **X: ロングキック** — 前方の味方 (見つからなければ入力方向) へ浮き球で
  強く蹴り出します。ハーフライン付近に到達するまで敵味方問わず誰も
  触れられません (トラップ・タックル・スライディング不可)
- ゴールキックのリスタートもこの操作で再開します

### クロス (センタリング) とヘディングシュート

相手ゴールラインから 30m 以内 (ペナルティエリアの奥行きよりだいぶ手前、
自陣寄りまで含む) で、ペナルティエリアの幅より外側 (サイド) に居るとき、
ボールを持って **Z を 0.35 秒以上長押し**すると、自動的にクロスが上がります
(短く離せば通常のパスのまま)。狙う先は相手ボックス内で最もゴール中央に
近い味方 (居なければゴール前中央)。CPU もこの位置に来ると同じ判断でクロス
を上げてきます。

クロスが飛んでいる間は、ダイレクトシュートと同じ「光る窓」の仕組みが
そのまま**ヘディングシュートの受付窓**として働きます。受け手が操作キャラの
ときにボールが届く直前の 0.2 秒間だけ光るので、その間に **X** を押すと
トラップせずヘディングで叩き込めます。威力は X 長押しのフルパワーシュート
と同じです。

- 着地するまで敵味方問わず誰も触れられません (GK のロングキックと同様)。
  誰もタイミングよく X を押せなければ、着地後は通常のルーズボールになります
- 調整は `js/config.js` の `CROSS_CONF` (発動までの長押し時間・初速)

## スマホにインストールする (PWA)

このゲームは PWA (Progressive Web App) 対応です。`http://` または
`https://` で配信されているページを Android Chrome で開くと:

1. メニューから「ホーム画面に追加」(またはアドレスバーのインストール
   アイコン) をタップ
2. ホーム画面にアプリアイコンが追加され、そこから全画面・横向きで起動
3. 一度開いた後はオフラインでも遊べる (Service Worker がゲーム一式を
   端末にキャッシュ済みのため)

**注意:** `file://` で直接開いた場合や、ファイル 1 枚だけを共有する形では
Service Worker が登録できず、この機能は働きません。`manifest.json` /
`sw.js` / `icons/` を含むリポジトリ一式を GitHub Pages などの静的ホスティ
ングで配信してください (このリポジトリなら Settings → Pages で有効化する
だけで動きます)。

新しいアイコンに差し替えたり、キャッシュ対象ファイルを追加・変更した
場合は、`sw.js` の `CACHE_NAME` のバージョンを上げてください (古いキャッ
シュは次回起動時の `activate` イベントで自動的に破棄されます)。

## グラフィック

選手は 16x16 のドット絵スプライトで描画され、アクションに応じてポーズが変わります:

脚を出す (AI選手のカット) / 転倒
