# 2Dサッカー (ymt-game01)

ブラウザで遊べる 2D サッカーゲームです。ウイニングイレブンのように、
ボールに関わる 1 人をユーザーが操作し、残りの選手は AI が自動で動きます。

- 7 人制 (GK + フィールド 6 人)、2-3-1 フォーメーション
- 味方チーム **BLUES (青)** vs 敵チーム **REDS (赤)**
- 前半 5 分 + 後半 5 分 (タイトル画面の設定で 1〜10 分に変更可能)
- カメラはボールを追従してスクロール。右下のミニマップで全体の陣形を確認できます

## 起動方法

`index.html` をブラウザで開くだけで動きます (ビルド・外部ライブラリ不要)。

ローカルサーバーを使う場合:

```bash
python3 -m http.server 8000
# → http://localhost:8000 を開く
```

## 操作方法

| キー | 攻撃時 (ボール保持) | 守備時 |
|---|---|---|
| 矢印キー | ドリブル | 移動 |
| Z | パス (入力方向の味方へ) | スライディング |
| X | シュート (長押しで強く、上下入力でコース調整) | スライディング |
| C | ダッシュ | ダッシュ |
| Space | - | 操作選手の手動切替 |
| Shift | ダッシュ (攻守共通) | ダッシュ |
| Esc | ポーズ | ポーズ |
| Enter | タイトル: 試合開始 / ハーフタイム: 後半開始 | 同左 |

### 操作キャラの切替について

- 味方がボールを持つと、自動で保持者に操作が移ります (パス時は受け手へ)
- 守備時は「ボールと自ゴールを結んだ直線」の近くに居てボールに近い味方へ
  自動で切替わります。ボールより敵ゴール側 (ゴールサイドでない) の選手は
  守備に間に合わないため、大きく減点して選ばれにくくしています
  (`js/match.js` の `defensiveScore`)
- 頻繁に切替わりすぎないよう、以下のヒステリシスを入れています
  (`js/config.js` の `SWITCH_CONF`)
  - 切替後 0.9 秒間は自動切替をロック
  - 候補の優先度が「現在の操作キャラ × 0.68」より良い、または差が一定以上
    開いたときだけ切替
- Space キーで手動切替: 守備優先度の高い順に巡回します (押すたびに次の候補へ)。
  手動切替後は 1.5 秒間、自動切替をロックしてユーザーの選択を優先します

## ルール (簡略化)

- タッチラインを割ると相手ボールのキックイン
- ゴールラインを割るとゴールキック / コーナーキック
- ファウル・オフサイドはありません
- GK はペナルティエリア内でシュートをキャッチし、少し保持してから味方へフィードします。
  GK がボールを保持している間、相手チームはプレスに来ません (ボールも奪えません)

## グラフィック

選手は 16x16 のドット絵スプライトで描画され、アクションに応じてポーズが変わります:
走行 (2フレームアニメ) / キック (パス・シュート) / スライディング /
脚を出す (AI選手のカット) / 転倒

## ファイル構成

```
index.html        エントリ HTML (画面オーバーレイ含む)
css/style.css     画面・UI のスタイル
js/config.js      定数・フォーメーション・難易度・ユーザー設定
js/utils.js       ベクトル演算などの汎用関数
js/input.js       キーボード入力管理
js/ball.js        ボールの物理と保持状態
js/player.js      選手 (状態機械・守備アクション・AI)
js/team.js        チーム (フォーメーション・チェイサー割当)
js/match.js       試合進行 (操作切替・パス/シュート・ゴール/アウト判定)
js/render.js      カメラ・描画・HUD・ミニマップ
js/main.js        メインループと画面遷移
```
